# Incertae Sedis

Converted to Jekyll minimal-mistakes theme for GitHub Pages hosting.

## Getting Started

### Prerequisites
- Ruby 2.7+
- Bundler

### Installation

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000` to view the site.

### Build for Production

```bash
bundle exec jekyll build
```

## Structure

- `_pages/` - Static pages (Nosotros, Servicios, Portafolio, Blog, Cursos, Contacto)
- `_posts/` - Blog posts
- `_layouts/` - Custom page layouts
- `_includes/` - Reusable components
- `assets/` - Images, CSS, JS
- `_config.yml` - Site configuration

## Theme Customization

Minimal Mistakes provides extensive customization. See [documentation](https://mmistakes.github.io/minimal-mistakes/) for options.
